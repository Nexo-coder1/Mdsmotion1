GitHub से लाइव करने की सेटिंग

यह सेटिंग एक बार करनी है। इससे बदलाव सीधे GitHub पर जाएँगे और वीडियो व इमेज आपकी ही साइट पर रहेंगी।

Token कैसे बनाएँ
  1. GitHub पर लॉगिन करें, फिर अपनी प्रोफ़ाइल फ़ोटो → Settings → नीचे Developer settings।
  2. Personal access tokens → Fine-grained tokens → Generate new token चुनें।
  3. Repository access में Only select repositories चुनें और अपनी रिपॉज़िटरी (जैसे Mdsmotion1) चुनें।
  4. Permissions में Contents को Read and write करें।
  5. Generate token दबाएँ, दिखा हुआ token कॉपी करके ऊपर Token वाले बॉक्स में चिपकाएँ और सेव करें।

Token केवल इसी फ़ोन/ब्राउज़र में सेव होता है। अगर token खो जाए या किसी और के हाथ लगे, तो GitHub पर जाकर उसे Delete कर दें और नया बना लें।
