GitHub publishing setup

Do this once. Publishing writes directly to your GitHub repository, and videos and images are stored on your own site.

How to create a token
  1. On GitHub, open your profile photo → Settings → scroll down to Developer settings.
  2. Go to Personal access tokens → Fine-grained tokens → Generate new token.
  3. Under Repository access choose Only select repositories and select your repository (for example Mdsmotion1).
  4. Under Repository permissions add Contents and set it to Read and write.
  5. Click Generate token, copy it and paste it above, then save.

The token is saved only in this browser. If it is lost or exposed, delete it on GitHub and create a new one.
